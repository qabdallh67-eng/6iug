# مشروع السبورة التاريخية

هذا المستودع مخصص لمشروع السبورة البيضاء التعليمية.

## تشغيل المشروع
1. ارفع ملفات المشروع الأصلية إلى جذر المستودع، مع الحفاظ على مجلدات `src` و`public` وملف `package.json`.
2. افتح تبويب Actions وشغّل **Build Whiteboard App**.
3. بعد نجاح البناء، افتح تشغيل الـ workflow ونزّل artifact باسم `whiteboard-dist`.

## تصدير MP4
البناء على GitHub Actions ينتج ملفات الموقع فقط. تصدير الفيديو MP4 يتم من داخل التطبيق في المتصفح عبر نافذة التصدير، وليس من خطوة بناء Vite. اختر دقة 1080p من إعدادات التصدير إذا كانت متاحة في الواجهة.

> تنبيه: المستودع كان فارغًا عند إعداد هذا الملف؛ يجب رفع ملفات المشروع الأصلية قبل تشغيل البناء.
